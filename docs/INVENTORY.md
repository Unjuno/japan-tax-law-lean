# Phase A — 対象法令インベントリ報告（2026-11-15 現在）

本レポートは、日本の税法体系の対象法令母集団を公式法令一覧から列挙し、
2026-11-15 時点の適用版を固定した結果を記録するものです。
**本件は台帳の構築であり、各法令の法解釈の正確性・欠陥の有無を意味しません。**

## 出典とハッシュ

- 全現行法令一覧（e-Gov `lawlists/1`、2026-11-15 取得）: `scripts/law_audit/inventory/lawlists_1.xml`
  - SHA-256: `19DBCCB28E088599A3F2FEAC076C4C082C59265259D2C2DA671099436287A75E`
  - 9,001 件（カテゴリ: 全法令）
- 適用版の選定規則: `scripts/law_audit/inventory/build_inventory.py::select_revision`
  - `current_revision_status == "CurrentEnforced"` を優先。なければ施行日 ≤ 2026-11-15 の最新かつ未施行でない版を `historical_fallback` とする。いずれも存在しなければ **完全未施行 (`fully_unenforced`)** と記録し、検証対象から外す。

## 母集団の定義と完全性

- キーワード `税` を `law_name` に含む法令を列挙 → **327 件**（法律 74 / 政令 113 / 省令・府令 140）
- **判定の限界（明示）**: このキーワード抽出は決定論的で再現可能だが、主題が税であっても名称に `税` を含まない法令については取りこぼしうる。
  - 例: 所得税法施行規則など名称に「税」を含むため含まれるが、上乗せ例外は原文照合で確認した（`所得税法施行令` `法人税法` … 全て検出）。
  - 名称に「税」を含まない税制関連法（例: `租税条約実施関係` は含む／統計法 は税制外）は本台帳の監査対象外として登録はされており、
    「未取得・未対応を成果に含めない」原則に従い成功件数に算入していない。
- **地方税条例**（1,788 自治体）は全国単位の一覧に含まれず、自治体ごとの独立した法源である。本フェーズでは**列挙・取得未対応**として明示し、未検証のまま `unsupported` として扱う。対象に含めない根拠と再実行手順は README/PHASE_A.md 相当の注記どおり。
- **租税条約・通達・裁判例**は解釈補助レイヤーであり、法令本文の母集団に含めない（`category: tax_national` 外）。
- **改正法・経過措置**: 各ピン留め版は `law_revision_id` と改正法番号・施行日を台帳に記録。改正前の法令は公式一覧に存在する限り同一台帳の改正履歴から辿れる。

## 更新方法

```sh
python scripts/law_audit/inventory/build_inventory.py --fetch-raw   # 再取得（ネットワーク必要）
python scripts/law_audit/inventory/pin_revisions.py                 # 改正履歴ピン留め検証
python scripts/law_audit/inventory/validate_inventory.py             # 台帳検証（オフライン）
```

台帳は `data/INVENTORY.json`。対象法令の追加・廃止・改正は再取得 → 検証 → 台帳更新の順で追跡する。
