# Adversarial review — cycle-114 独立再抽出（技術的検証のみ）

- 日付: 2026-11-24
- 位置づけ: **技術的な原文照合・仕様対応のレビューであり、人間の法律的レビューではない。**
  法的レビューは `LEGAL_REVIEW_PENDING` のままとする。架空の承認記録は作成しない。
- 手法: 各モジュールの doc-comment に固定した法令ID・版から pinned raw JSON を読み、
  `Article` / `Paragraph` / `Subitem` の座標を使って該当文言を独立に再抽出し、
  Spec の定数・境界例と照合した。`transcription_audit.py` の needle は利用せず、
  抽出は別経路（原文ツリーの直接走査）で行った。
- H/T/D/C/U（スポンサー指針 §5）: H=反証可能な仮説, T=検証手続, D=判定,
  C=競合する読み, U=未解決の不確実性。

### LocalGrantTaxShares.lean — 地方交付税法 art.6の2 §2/§3（94% / 6%）

- pin: law_id `325AC0000000211` / revision `325AC0000000211_20261102_508AC0000000062` /
  raw `data/raw/325AC0000000211_20261102_508AC0000000062.law.json` /
  Article Num=`6_2`。
- 独立再抽出:
  - §2 ParagraphSentence#1: 「毎年度分として交付すべき普通交付税の総額は、
    前条第二項の額の百分の九十四に相当する額とする。」
  - §3 ParagraphSentence#1: 「毎年度分として交付すべき特別交付税の総額は、
    前条第二項の額の百分の六に相当する額とする。」
- 照合: 原文の「九十四」「六」「百分」を Spec の `94 / 100`, `6 / 100` と
  各々対応させた。二つの割合は別々の項にあり、一方の needle は他方の項には現れない。
  `agreeLocalGrantTaxShares` は 0, 1, 6, 31, 94, 95, 99, 100, 101, 10_000, 1_000_003
  の 11 点で実装と独立仕様の一致をカーネル決定する。
- 判定: **BY-DESIGN / CONFIRMED 0**。二項の割合の転記・下限切り捨て・境界
  （93/94/95, 99/100/101）に食い違いはない。
- H（仮説）: 「94% と 6% を取り違え、または片方の項の数値を他方に流用した」可能性。
  T（検証）: 二つの項を夫々独立に再抽出し、Spec の分子 94 と 6 を各項の原文と照合。
  D（判定）: BY-DESIGN / CONFIRMED 0。
  C（競合）: 「前条第二項の額」の算定を含む全域をモデル化したと誤読され得るが、
  実装は所与 `total` への割合適用のみに限定している。
  U（不確実性）: 端数処理・附則の特例・前条第二項の額の算定は未対応であり、
  法的効果の完全性は主張しない。

### StandingTimberDeferredRate30.lean — 相続税法施行令 art.28 §1（30%）

- pin: law_id `325CO0000000071` / revision `325CO0000000071_20260401_506CO0000000143` /
  raw `data/raw/325CO0000000071_20260401_506CO0000000143.law.json` /
  Article Num=`28`。
- 独立再抽出: §1「法第五十二条第一項第一号ロに規定する政令で定める割合は、
  百分の三十とする。」
- 照合: 原文の「三十」「百分」を `30 / 100` に対応させた。同条 §2 の
  「立木の価額が占める割合…いずれか少ない額」には「三十」が現れないため、
  §2 の文言が §1 の証跡を継承しないことを別途確認した。
  `agreeStandingTimberDeferredRate30` は 11 点で一致をカーネル決定する。
- 判定: **BY-DESIGN / CONFIRMED 0**。
- H（仮説）: 「§1 の 30% を §2 の比較計算（最少額選択）と混同した」可能性。
  T（検証）: §1 と §2 の文言を別々に抽出し、Spec に §2 の比較式が入っていないことを確認。
  D（判定）: BY-DESIGN / CONFIRMED 0。
  C（競合）: 「3/10 と 30/100 は同値だが、端数処理の順序で差が出る」読みがあり得る。
  実装・Spec とも Nat の `tax * 30 / 100` であり、丸めは切り捨てに統一した。
  U（不確実性）: §2 の比較計算、§3 の準用、延納許可・物納は未対応。

## 結論

三モジュールはいずれも **fidelity-only** の技術的照合に留まり、
「 techically verified / 形式化未完了 / 法的レビュー未完了 」を分離する。
CONFIRMED の法的誤りは 0 だが、それはレビュー済みを意味しない。
